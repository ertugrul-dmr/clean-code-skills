# Clean Functions

## F1: Too Many Arguments (Maximum 3)

```dart
// Bad - too many positional parameters
User createUser(
  String name,
  String email,
  int age,
  String country,
  String timezone,
  String language,
  bool newsletter,
) {
  // ...
}

// Good - use a class
class UserData {
  const UserData({
    required this.name,
    required this.email,
    required this.age,
    required this.country,
    required this.timezone,
    required this.language,
    required this.newsletter,
  });

  final String name;
  final String email;
  final int age;
  final String country;
  final String timezone;
  final String language;
  final bool newsletter;
}

User createUser(UserData data) {
  // ...
}
```

More than 3 arguments means your function is doing too much or needs
a data structure.

## F2: No Output Arguments

Don't modify arguments as side effects. Return values instead.

```dart
// Bad - modifies argument
void appendFooter(StringBuffer report) {
  report.write('\n---\nGenerated by System');
}

// Good - returns new value
String withFooter(String report) {
  return '$report\n---\nGenerated by System';
}
```

## F3: No Flag Arguments

Boolean flags mean your function does at least two things.

```dart
// Bad - function does two different things
void render(bool isTest) {
  if (isTest) {
    renderTestPage();
  } else {
    renderProductionPage();
  }
}

// Good - split into two functions
void renderTestPage() { ... }
void renderProductionPage() { ... }
```

## F4: Delete Dead Functions

If it's not called, delete it. No "just in case" code. Git preserves history.
